# CodeAlpha_Calculator

CodeAlpha Calculator

========================

ABOUT

This is a simple calculator web application developed using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

It provides a user-friendly interface for performing basic arithmetic calculations.

========================

TECHNOLOGIES USED

- HTML5
- CSS3
- JavaScript

========================

FEATURES

- Simple calculator interface
- Basic arithmetic operations
- Interactive calculator buttons
- Calculation results

========================

PROJECT STRUCTURE

- "index.html" – Calculator structure
- "style.css" – Styling and layout
- "script.js" – Calculator functionality

========================

HOW TO RUN

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
